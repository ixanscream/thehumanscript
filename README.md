## 3. THE CHAOS ENGINE: ALGORITHM SABOTAGE

Mekanisme untuk merusak akurasi profiling buzzer dan iklan korporat melalui **Data Poisoning**.

### A. Trigger Mekanisme

- **Trigger A (Global Command):** Arsitek mengirim sinyal sabotase ke seluruh jaringan.
- **Trigger B (Local Radar):** HP user mendeteksi anomali trending (lonjakan velocity tak wajar khas buzzer) dan melakukan verifikasi via konsensus Gossip dengan peer terdekat.

### B. Automated Stealth Sabotage

Menggunakan Headless JS & Hidden WebView untuk menyuntikkan _noise_ (gangguan) ke sistem pusat:

- **Search Spoofing:** Secara otomatis mencari hashtag target dibarengi dengan garbage keywords (resep seblak, ternak lele, marxisme).
- **Categorization Confusion:** Membuat algoritma gagal mengklasifikasikan topik, sehingga trending dianggap spam atau salah sasaran (iklan politik muncul di audiens yang salah).
